📡 อัปเดตราคาปัจจุบันแบบ Real-time (Google Finance)
หน้าเว็บนี้เป็นไฟล์ static เชื่อมต่อ Google Finance โดยตรงไม่ได้ (ติด CORS + ไม่มี public API ให้ใช้ฟรี)
วิธีที่ใช้ได้จริง: สร้าง Google Sheet ที่ดึงราคาด้วยสูตร GOOGLEFINANCE() แล้วเผยแพร่เป็น CSV ให้หน้านี้ดึงมาอ่านอัตโนมัติ (ดูวิธีทำแบบละเอียด)
ขั้นตอน (ทำครั้งเดียว ใช้ได้ตลอด):
1. เปิด Google Sheets → สร้างชีตใหม่
2. แถวแรกใส่หัวตาราง: A1=Symbol, B1=Price
3. แถวถัดไปใส่ตามนี้ (แก้ ticker ให้ตรงกับที่คุณถือ):
  • A2=USDTHB   B2==GOOGLEFINANCE("CURRENCY:USDTHB") ← อัตราแลกเปลี่ยน
  • A3=NVDA   B3==GOOGLEFINANCE("NASDAQ:NVDA","price") ← หุ้นนอก
  • A4=AOT   B4==GOOGLEFINANCE("SET:AOT","price") ← หุ้นไทย (ถ้าพิมพ์แล้ว error ให้ลองเปลี่ยนเป็น "BKK:AOT" แทน — Google บล็อกตลาด SET เป็นบางช่วง ถ้าไม่ขึ้นเลยระบบจะไปดึงจาก Yahoo Finance ให้อัตโนมัติแทน)
  • A5=BTC   B5==GOOGLEFINANCE("CURRENCY:BTCUSD") ← คริปโต
4. เมนู File → Share → Publish to web → เลือกชีตนี้ → format เลือก Comma-separated values (.csv) → กด Publish
5. คัดลอกลิงก์ที่ได้ (ขึ้นต้นด้วย https://docs.google.com/spreadsheets/d/e/...) มาวางช่องด้านล่าง
* ราคาในชีตจะอัปเดตเองทุกครั้งที่ Google Sheets sync (ปกติทุก 1-5 นาที) กดปุ่ม "ดึงราคาล่าสุด" ที่นี่เพื่อซิงก์เข้าหน้าเว็บ
